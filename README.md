# CollegeUp
College Up is a project i made for college exam.

# About
College Up is game about a college student pursuing his degree while facing all of the challenges he gets in College. The higher he goes, the harder the challenges.

## How to Run

### Pre-built Windows Version
1. Locate `ProjekUAS_3TIA.exe` in this repository.
2. Keep this file together with `ProjekUAS_3TIA_Data`, `UnityPlayer.dll`, `UnityCrashHandler64.exe`, and `WinPixEventRuntime.dll` in the same folder.
3. Double-click `ProjekUAS_3TIA.exe` to start the game.

### Run from Source
1. Install **Unity 2018.3.14f1** (or another Unity 2018.3 editor).
2. In Unity Hub, click **Add** and select the `ProjekUAS_3TIA` folder from this repo.
3. After Unity imports the project, open the scene `Assets/Scenes/MainMenu.unity`.
4. Press **Play** to run the game in the editor or build a standalone player from **File > Build Settings**.
   - The project uses the DOTween plugin located under `Assets/Plugins/DOTween`, so no additional packages are required.
